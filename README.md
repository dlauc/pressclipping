# Press clipping

Organisations and persons recognised in Croatian newspaper issues, linked to their
[poslovna.com](https://poslovna.com) pages, with the sentence each was named in.

**Page:** https://dlauc.github.io/pressclipping/

Current issue: *Jutarnji list*, 1 October 2026 (issue 43133).

Built automatically: Tesseract OCR, BERTić named-entity recognition, and poslovna's free-text entity
linker with a calibrated confidence. Only links above the calibrated threshold are shown
(organisations from 70 %, persons from 90 %). Measured on unseen issues, those links were right
88–100 % (organisations) and 100 % (persons) of the time. Errors remain; see the method note on the page.
